# EduLab SQL 0.15.0：Win7 截图采集版

适用 Windows 7 SP1 64位、Chrome 69.0.3497.81。EXE内置Python 3.8.10、41个应用本地UCRT DLL及受限云端连接，无需安装Python或重启电脑。

1. 关闭旧学生端服务和浏览器页面，双击新 `EduLab-SQL.exe`。它自行释放运行时；备用 `Start-Classroom.cmd` 需完整解压ZIP并保留runtime目录。
2. 云端直连配置优先于历史本地桥接配置，截图上传不依赖Mac、教师本机服务或3005端口。COS永久密钥只在后台，不打包进学生端。
3. 准备课与四次正式实验仍按当次任务进入，每课独立对话。正式身份至少10轮有效对话，无上限；计时均为建议。量表、测评和精神努力必答，不采集成绩估算。
4. “柴博泉”“测试1”“测试2”“test_3”等保留测试规则：全课开放、可跳过前测问卷、不等待分组；已作答的数据和截图仍保存，但不参与正式分组。
5. 独立实操保留SQL、结果文本与核验说明，并支持选择或粘贴1—3张本人运行截图；正式身份至少1张，测试身份可不传。截图按设备、学生UUID、课次、作品及附件UUID绑定，不发给AI。
6. 图片先写入本机持久文件，再自动上传私有COS。文本、截图均确认后才显示“进度已同步 · 云端归档完成”。断网或服务关闭后，同班同名重新进入可恢复进度并补传；不要清空 `%LOCALAPPDATA%\EduLab-SQL`。
7. 教师后台“实操与后测”查看当课截图。学生线上版继续暂停，分析工具与采集页面分离。

兼容验证使用Python3.8、ES2017/Chrome69脚本和Win7目标PE/UCRT检查；最终仍需在机房电脑验收启动、AI、图片上传和云端同步。机房还原可能清空尚未上传的本机数据，离开前须确认归档完成。
