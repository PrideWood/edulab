# EduLab SQL 0.14.0：机房数据采集版

适用 Windows 7 SP1 64位与 Chrome 69。随包提供 Python 和完整 UCRT，无需安装系统运行库或重启电脑。

1. 关闭旧程序与旧页面，完整解压新包到新目录，双击 `Start-Classroom.cmd`。保留 `runtime`。
2. 前测、问卷、精神努力与测试题均必答，不采集成绩估算。
3. 准备课与正式课均至少完成10轮有效对话；一轮是学生发送并获得学徒成功回复，失败或中断不计数。没有轮数上限。
4. 达到10轮后可继续交流，也可主动结束、填写精神努力卡并进入实操。所有计时仅作建议，不等满、不强制关闭、不自动代交。
5. 测试身份“柴博泉”“测试”“test”“ceshi”保留前测问卷，自动使用默认L学徒，不等待分组；正式身份仍须教师按基线分组。
6. 每次保存同时写入持久备份队列；模型回复期间也上传。网络失败自动重试，云端回执匹配后才标记同步。离开或关机前确认“进度已同步”。机房还原保护不会被本程序改动，尚未上传的本机文件仍受还原配置影响。
7. 教师后台只管理课堂、原始数据、评分和备份；分析工具独立放在 `analysis/`，不接入采集页面。学生线上版暂缓开放。

正式学生记录和分组不清空。既有已进入实操/已完成的记录保留原流程；尚未完成的旧自动收束会保留历史痕迹并按新规则恢复。
