学生端仅提供姓名确认登录、前测与问卷、三课虚拟学徒交互、实操计时和后测。教师管理入口、口令登录与本机管理接口已移除；旧管理接口返回410。原本机历史档案及旧文件保留，不删除研究数据。

## 教师统一管理

使用原EduLab管理员账号登录 https://edulab.dacnote.com/admin 。侧边栏集中为：

- **本地数据备份**：当前班级、测试身份与新实验的云端备份，支持查询、完整记录、导出与原有回收站。旧平台的在线测试记录保留在同一入口的独立折叠区，明确显示在线来源。
- **当前实验控制**：SQL课堂开放、前测分组、提示词、共享DeepSeek模型设置、实操用时与后测评分，均保存在云端数据库。
- **科学教育归档**：科学教育在线记录及三、八、九班的正式本地备份，提供独立查看和导出。归档仅分类与标记，不复制、清空或改写原始消息与备份。

## 云端控制同步

学生机约每3秒通过本机转接读取云端配置、属于本设备身份的固定分组及教师评分。首次同步未完成或中断超过2分钟时，不再开放新的课堂入口；本机已保存内容保留，实操计时不暂停。定时开放使用云端时间校准。新配置仅作用于之后开始的课堂，已有课堂继续使用开始时的时长和提示词快照。

课堂入口按班级与课次设置关闭、立即开放或定时开放（可选截止时间）。学生还需完成本课交互和实操才能参加后测，学徒说“学会了”不会提前解锁。

云端新分组集中使用已确认备份的前测，以每班姓名匹配固定组别；同分顺序随机，成绩相邻配对，每对分入L/T，从1500个随机候选中尽量减小组间均分及样本标准差差异。测试身份默认排除。该班存在未完成前测时拒绝分组；已有固定云端分组不重新随机。迁移时保留已有本机固定组别，不能把已接受某种处理的学生重新分组。请核对全班名单已完整上传，有限样本不保证两组完全相等。

## 学生身份与研究材料

班级固定为计网2541、计网2542、计网2543；学生填姓名并在弹窗确认。内部UUID不在页面显示。同一班级同一姓名在本机恢复原档案；同名学生需在研究前约定不同登记名称，避免合并。换电脑不自动迁移本机档案。

20题前测每题5分；13题问卷仍是待验证的改编稿。平台显示四次课：项目五简单查询、项目五查询中的常用处理、项目六聚合与分组、项目六子查询与比较。即时后测参考项目五、六课后练习知识点改编，每课10道单选题，每题10分。题库及答案见 `../../docs/sql-posttests.md`。当前模式可选择演示规则或真实DeepSeek；真实模式需要在EduLab“当前实验控制→共享模型”中保存原共享Key。演示学徒不是可靠的掌握评估，也不能代替两组操纵检验。

提示词结构：共用学徒规则＋L/T策略之一＋当课内容及检查点＋可见解释状态。两组调试使用已保存版本，独立于学生数据。每课开始保存配置与提示词版本快照，教师修改不追溯改变旧轮次。

## 计时、录屏与评分

独立实操点击开始时计时，在电脑SQL Server操作后粘贴代码和结果，确认提交停止；到时保存已有草稿并标记超时。记录的是任务总经过时间，包含查教材与思考，不是SQL Server前台活跃时间；分析应结合正确性和完成状态。

教师可从“当前实验控制→实操与后测”导出四课即时后测CSV、各阶段用时CSV和实验完整JSON。新后测采用与前测一致的单选界面，自动保存草稿、答案、得分、题目版本与快照、完成状态和用时；超时保存已有答案。即时后测只作为结果测量，不参与分组、学徒策略或任务开放条件。提交或超时后按原流程完成本课，不设及格线。前测分组规则不变。新建课堂轮次冻结新版题目；已存在轮次保留旧混合题及原有教师评分，不改写历史成绩。

可要求学生同步录屏：点击开始实操前启动、提交后结束，以“班级_姓名_第X课”命名，视频单独收集。应用不自动录屏、不上传视频。延时纸质后测不在应用内实现。

## 本机数据与云备份

本机SQLite使用WAL及FULL同步。学生原话先保存，再请求模型；重复请求编号幂等，失败不自动重发模型调用。草稿约400—500毫秒去抖，确认提交等待保存；断电前尚未发送的按键不保证恢复。

备份队列只有收到相同上传编号及SHA256回执才标成功，失败稍后重试。保留姓名、班级、前测及问卷、固定分组、提示词版本、完整对话、SQL和结果、阶段用时与评分，不含API Key或会话凭证。教师管理使用原EduLab管理员认证，不再在学生机生成教师口令。

旧科学教育Light/LAN的`science-backup.disabled`保留。历史数据库未删除；本机源码开关不会远程改变已分发的旧EXE。

## 元认知13题与导出（2026-11-08）

课前：教师在当前实验控制同时开放“基础前测”和“课前问卷”；学生须先提交SQL前测，之后自动进入13题问卷。问卷在平台训练和正式教学前完成。课后问卷须完成第三课独立后测才可填写，题干与选项相同。

问卷逐次修改保存到本机SQLite草稿；提交后锁定，保存版本、题号、题目、指导语、选项、逐题答案、监控/评价均分与起止用时。历史问卷不会补写为新版本。

管理员“实操与后测”提供基础前测CSV、元认知前后问卷CSV、前测/问卷/三课结果合并CSV及完整JSON。以“设备编号:学生UUID”为研究记录键，不能按姓名或CSV行号连接。前后问卷单独导出每个档案有两个时点行，未提交显示未提交且分数留空。同班同名多档案明确标记，人工核对后决定是否同一人；跨电脑不自动合并。合并CSV一档案一行，含逐题原始答案、问卷快照、三课SQL与对话完整轮次JSON，优先采用云端教师评分。导出身份不一致时拒绝生成CSV。

人工测试建议：用新测试姓名验证前测前问卷锁定；前测后自动进入；填几题返回再进入草稿恢复；提交后无法覆盖；再用另一测试姓名填不同答案，比较独立CSV与合并CSV的研究记录键和逐题值。等待云端备份接收后再导出，检查备份接收时间。服务代码更新后需重启本机启动器；线上后台需另行发布才生效。

## 取消次数上限及解锁容错（2026-11-08）

教学时段内不限制追问次数，每个学生同时只处理一条请求，时间结束后停止新增请求。旧课堂快照里的max_questions字段仅作历史保留，不再限制发送。T组仍按六个固定检查点顺序循环，失败请求不推进检查点。暂不增加知识进度条。

自动实操开放要求教学时段结束且学生已经发送讲解，不再要求模型成功回复。只要存在本课已接受的学生消息，模型失败、重启中断或仍在整理回复均不阻挡按时进入实操；无讲解记录仍提示联系教师，教师手动关闭/定时安排继续生效。没有成功模型回复就进入实操时写入practice_without_completed_ai_reply事件，保留真实失败记录，研究分析中需识别这类异常暴露。迟到回复始终附着原课堂，不重置实操时钟。

模型请求携带最近24条对话和已有知识状态，避免对话增长造成请求超限；本机及备份保留完整对话，不裁剪研究记录。
