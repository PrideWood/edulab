# 0.10.0：有限对话与研究测量操作说明

研究协议：sql-lt/1.1。在既有业务工单与两班配置上落实P0分组、6/12轮边界、精神努力和预估分；不设最低字数。精神努力是本次采纳后的核心测量，其他候选动机、投入与信任量表未加入。

## 教师开始前

1. 分发0.10.0；升级时先关闭旧服务窗口，不删除原数据目录。旧版不能执行本协议，不能只更新网页后台就继续用旧学生程序。
2. 后台保持2531/2532，预计31/38；预计人数不限制登录。新增班级继续在班级管理保存后自动更新登录下拉框。
3. 同时开放基础前测和课前13题问卷，学生完成并备份后，在各班内部按基线分配L/T；P0之前完成。测试身份默认排除。不要按准备课表现重新分组。
4. 核对客户端协议、旧接触和复用基线标记；旧方案记录保留在scheme_history/research_history，不会改写为新组别。
5. AI立即开放以保存时刻为共同起点；定时开放使用指定起点。已经开启后刷新/改其他设置不会重置起点；需要新时段时先关闭并保存，再重新开放。正在进行的课堂保留原配置快照，勿中途改时长或问题序列。

## 学生流程

T的实际提问由程序从有限题库选择，模型不替它重排；仅检查隐藏target编号不足以证明固定策略。两组若六项均被模型记录为已讲解，只确认记录，不再重复提问；该记录不是学生掌握的客观证据，关闭仍遵守共同时间、上限或主动结束规则。

P0最多6个成功问答轮，正式课最多12轮。失败/中断请求不消费机会；重试保留来源。达到上限后允许一次收尾回答，程序只确认保存，不再发新问题；最后60秒不再发起新问题。慢回复若跨入收尾窗口，也不再显示新的提问。学生可主动结束，随后静默整理到共同窗口结束，不能提前进入实操。

共同窗口结束出现九点精神努力卡，无默认值，可暂不回答；P0为填写练习，正式课分别记录。高努力不等于差表现，不给高低评价。前测与实操提交前预估0—100分，也可暂不回答；提交后不可回填。问卷未答项留缺失，监控至少6/7、评价至少5/6才计算维度均分，不默认补0或中间值。

独立实操开始后，学生接口和页面不再返回本课聊天；后台研究记录仍完整。实操与概念测的建议计时不自动代交，迟交与实际用时保留。精神努力只问教学徒阶段，不混入实操负担。

## 研究测量与ENA页

设置各班T4和D1计划日；D1仍为纸笔20分钟，目标为T4后7天、允许±2天。后台可下载学生卷和教师评分材料，勿将教师卷发给学生；记录实际日期、预测分和缺席情况。超窗标记保留，缺席不记0。

实操和D1录入四项评分；首次分、第二评分和最终分/单评分分别保留，修订有审计与乐观锁，避免另一窗口覆盖。研究成绩不在学生页面显示。后测单选自动分与人工实操/D1分不是同一张成绩表。

ENA导出是编码准备文件：保留角色、原序号、课次、消息、请求状态、收尾/重试与可编码标记，不自动执行ENA、不生成未经人工核验的节点。正式导出默认排除测试身份；含测试预览需显式选择。P0和四次正式课分别标记。

导出用稳定假名替代直接身份，不含姓名列和截图；已知学生姓名在文字中替换，但仍需人工复核其他身份线索。假名化不等于绝对匿名。失败/重试消息不删除，避免人为改变邻接关系。零内容和不可估计网络不能反过来成为删除主要成绩样本的理由。

## 部署与私有材料

迁移0029新增研究评分和私有纸卷表，保留原学生、分组和成绩。学生账号只能通过受限同步函数读取所属设备数据，不能直接读取评分表或私有材料表。新协议激活时旧课堂在本机另存历史，不静默变成新的L/T准备课；旧试测切课命令按研究版本隔离。

延时学生卷与教师答案不随源码、网页前端或Windows程序打包。使用有数据库部署权限的账户，从授权私有文件导入：

```sh
node scripts/import-sql-study-papers.mjs --student /private/path/student.md --teacher /private/path/teacher.md
```

同版本不同内容拒绝覆盖，应升版后明确迁移。后台下载必须登录；缺少材料时返回明确未配置提示。正式环境已由本次部署导入校验，源码独立部署的新环境仍需提供自己的私有文件。

## 验证边界

自动化测试覆盖预算/计时、最后回答、迟到回复、可选精神努力、预估分不可事后改、问卷缺失、历史保留、版本命令隔离、评分校验与假名化导出。另做浏览器流程和合成对话的真实模型检查。尚未在目标Windows机房运行，因此仍需用测试身份验收安装、学校网络、模型与备份；这些检查不替代正式研究前的材料负担和操纵有效性试测。
