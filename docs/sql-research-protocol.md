# 0.12.0 当次任务版操作说明

保留确定的准备课P0与四次正式实验、固定L/T分组、前测与13题问卷、精神努力卡、预估分、实操评分、纸笔D1及ENA编码准备导出。只采用当前方案，后台不再显示已放弃方案的配置历史。

## 教师操作

1. 学生端统一升级0.12.0，先关闭旧程序，保留正式学生的数据目录。
2. 后台“当次任务”中，分别为2531、2532选择本次课次并保存。默认准备课P0，后续由教师切换至正式第1—4课；不设置开放日期、开放时刻或截止时刻。
3. 学生只能进入当前指定任务。完成后等待教师切换，不自动解锁下一课，也不能继续修改其他课的任务。切换课次前核对提交情况；缺课与未完成按实际记录，不伪造完成。
4. 前测和课前问卷无需等待定时开放。正式学生完成基线后在班内分组，之后跨课固定；测试账号不参与正式分组。
5. 柴博泉、测试、test、ceshi和原已标记的测试身份始终排除；回收站身份不参加分组与平衡统计。测试账号完成真实前测和问卷并同步后自动使用L学徒，已有固定组别保留；交互前可选T。
6. “试测课堂”可以切换或重置指定测试账号的课次和轮次机会。普通学生不可使用此入口。

## 学生流程与计时

每次只显示当次任务。依次教学徒、独立SSMS实操、测评；实操开始后聊天封存。P0最多6轮，正式课最多12轮，失败请求不消费机会，上限后允许一次收尾回答，不设最低字数。

教学徒累计时长：P0为15分钟、正式课20分钟。只在对话页面可见且窗口处于前台时计时；返回首页、切换窗口或关闭页面暂停，返回后续计。普通关闭即时上报暂停，异常断电或进程崩溃由最长4秒的心跳租约兜底。最后60秒只收尾，不再发新问题。课堂跨日、晚进入均不扣掉未使用的时间。

对话收束后仍可在本页面整理；累计时长结束后填写九点精神努力卡，无默认值，可暂不回答，再进入独立实操。前测和实操提交前预估0—100分，也可暂不回答。提交后不可回填。问卷缺项留空，不默认补零或中间值。

T的实际问题由有限题库按顺序产生，L按可见解释调整。六项被模型记录为已讲解时，只确认记录，不把模型状态当作客观掌握证据。实操与测评沿用当前提交规则，不因统一截止时刻无法进入。

## 测试清理与历史

本次清理前，在部署工作目录保留权限受限的私有备份。仅清理SQL实验的测试身份及其测试分组、评分、试测命令和快照；正式学生和其他应用数据保留。旧测试身份列入退役名单，旧客户端补传不会进入当前名单。

新客户端登录旧测试账号时，将本机旧测试记录封存在退役测试表，停止补传旧身份，创建新的测试身份，从前测与问卷重新开始。已经登录旧身份的页面会要求重新登录。正式学生不会执行这项清理。既往正式记录不用于反推新的有效计时；未完成旧时段的累计时间重新开始并保留旧计时信息，已完成实操记录不改写。

已放弃方案的旧配置不再出现在当前后台版本列表中；必要的审计备份与兼容读取代码不参与新任务流程。其他科研文档不在本次清理范围内。

## 研究后台

研究评分保留首次、第二评分、最终结果与审计锁；缺席不记零。D1仍为T4后7天、允许±2天的纸笔测验，20分钟；日期是研究记录，不是学生平台入口的定时锁。学生卷、教师卷仅登录后台下载，不随学生程序或公开源码打包。

ENA导出为人工编码准备文件，保留角色、顺序、成功/失败、收尾和重试，不自动做ENA。默认排除测试身份，使用稳定假名，不含姓名列或截图；文字仍需人工检查身份线索。正式分析请区分旧计时与前台累计计时，完整JSON保留其标记。

## 版本边界

后台与数据库已支持自动试测；取消日历限制、当次任务约束和前台暂停计时要求0.12.0学生端。旧版无法仅靠刷新网页获得全部行为，不能混用进行正式实验。三种Windows包均需在目标机房用测试身份验收安装、校园网络、模型和备份。

## 本机房确定配置

Windows 7 64位，Chrome 69.0.3497.81；分发Win7 x64包。打包时将学生脚本转换为ES2017，补齐Object.fromEntries、globalThis、Array.at、UUID及requestSubmit接口，并为不支持flex gap、新选择器和CSS min()的环境提供回退。原始开发脚本保留现代语法，Windows包使用转换后的脚本。语法与接口测试不等于真实机房验收。

线上入口：https://edulab.dacnote.com/sql-student。本机优先使用Start-Classroom.cmd；两种方式与排障边界详见docs/sql-dual-deployment.md。
