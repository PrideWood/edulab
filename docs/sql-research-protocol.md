# 0.14.0 课堂与数据采集操作说明

准备课P0与四次正式课继续使用现有数据表和工单，L/T跨课固定；每班只开放教师指定的当次任务。

- 准备课先完成前测与课前问卷，正式身份等待教师分组。测试身份自动获得默认学徒，也需完成前测问卷。
- 每课至少10轮有效对话，无上限。失败/中断不计有效轮数，模型回复未完成时不能结束或进入下一环节。
- 所有计时为建议。10轮完成后可立即主动结束，填写必答精神努力卡后开始SSMS实操；无需等到建议时长。进入实操后不能继续AI。
- 实操、测评、问卷均由学生完成后主动提交；不能留空，不自动代交。已提交记录不能覆盖。
- 对话前台累计用时，离开暂停，超过建议时间仍可记录实际用时。

## 采集与备份

本机保存与备份队列在同一事务完成。只合并尚未发送的完整快照，最新快照包含所有早期消息、事件、答卷和草稿。模型请求进行中也上传；失败重试，程序中断后恢复。云端回执必须匹配上传编号和SHA256才确认同步。待确认内容不因网络失败丢弃。

学生端显示同步状态和重试入口；教师后台显示最近云端接收时间，每15秒刷新原始记录。后台无法看到尚未到达云端的离线内容。机房存在还原保护，关机前应核对学生端“进度已同步”和后台对应记录。

## 教师后台

课堂总览与备份、班级、当次任务、前测分组、学徒提示词、作品与后测、试测课堂、共享模型分区显示。支持班级/姓名筛选，评分仍在作品与后测中录入。

不显示研究测量、ENA或统计分析模块。保留原始JSON/CSV导出，编码、统计与ENA在收集结束后独立处理；不会删除已有数据。

## 升级

使用0.14.0新包，关闭旧窗口后启动。不要删除 `%LOCALAPPDATA%\EduLab-SQL`。既有完成记录保留；未进入实操的旧自动关闭记录保留历史痕迹并恢复交互。建议在一台机房电脑复测登录、十轮交互、结束卡、提交和云端同步后再统一使用。
