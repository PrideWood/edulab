## 脚本使用

原导出含CREATE DATABASE固定物理路径、CONTAINMENT、LEDGER等较新服务器选项，不能照搬到旧机房环境。数据库兼容级别100不意味着整份导出脚本可在SQL Server 2008执行。

已有教学库：运行“数据库核对_只读导出.sql”核对即可。

需要新练习库：先在SSMS手动建立空的专用库，再审阅并运行“教学数据库_空库初始化_SQLServer2008.sql”。该稿仅含六表及68条原始INSERT，保留NULL记录；不会覆盖已有用户表。尚须在实际SQL Server上执行验收。
