# 多实验与分组入口

## 教师操作

1. 登录 `/admin`，在左侧“当前实验”选择实验。点击“新增实验”会复制当前已保存的任务、规则和智能体配置；不复制被试、分组入口或聊天记录。复制后可以独立修改新实验。
2. 保存任务和交互规则。在“智能体与入口”中展开 API 配置，为各个智能体配置名称、Bot ID 和 Token，并测试连通性。
3. 在“创建分组入口”填写分组名称，选择“固定智能体”及对应智能体，点击“生成分组链接”。例如，为 A 组和 B 组各创建一个入口。这些入口可同时使用，不再需要轮流切换一个开放场次。
4. 点击对应入口的“复制智能体信息与链接”，剪贴板同时包含实验名、分组名、智能体名称、分配方式和完整链接。复制内容不包含 API Token 或数据库信息。
5. 若研究设计要求随机分组，选择“均衡随机分配”，选择至少两个智能体，为所有学生分发该组的同一个链接。仍沿用原有均衡随机算法，不把随机研究改为学生自行挑选智能体。
6. “停止新报名”只阻止新的被试从该入口进入。已有会话及恢复不受影响。再次开展不同任务或一批新实验时，新建对应入口，保留原入口及其记录。
7. 参与者列表可以按分组入口筛选；交互 ZIP 和身份 CSV 按当前实验和所选入口导出。全部分组视图才允许删除整名被试的记录，避免把部分对话计数误认为其全部记录。

不同实验的入口请分别分发。分组名称和智能体名称属于教师管理信息；学生聊天页继续使用原来的统一助手名称。若需要盲法，请在发给学生前调整复制内容中的内部名称。

## 短链接和恢复

新链接类似 `https://你的域名/join/k7rx-v4mz`。入口码为随机 8 位，分为两段，避开 `0、1、i、l、o`；不同短码至少有 4 个字符不同，避免递增编号造成相近链接。支持大小写和省略横线输入，不会把拼错的码自动指向近似组别。数据库唯一索引和分配锁防止并发冲突。完整域名长度取决于部署域名，后台始终复制当前访问域名。

每个入口使用独立的 HttpOnly 会话 Cookie。打开 B 组链接不会带入 A 组会话，同一浏览器也可以保存不同实验的会话。刷新原入口会自动载入该入口的会话；会话过期、浏览器数据清除或换设备后，回到原入口，选择“继续之前的实验”，输入编号和原学号。历史未填学号的记录使用原姓名核验。

编号仍然使用实验内的 `P001 / T001` 规则，并非全平台学生账号。两个实验可以都有 `P001`，数据库与恢复通过实验、入口和会话共同区分。姓名相同不会混用记录；学号首尾空格被清除。学号用于身份核验，不会仅凭姓名或学号自动合并被试。已经参加者应恢复原记录，重复选择首次参加会被视为新的报名。

短链接是分组入口，不是个人身份凭证。个人记录仍需原会话凭证或“编号 + 原身份”校验才能访问。教师应按研究设计分发链接；如果把多个组链接全部公开，尚未报名的学生仍可以选择从哪个公开组报名。

## 数据和兼容

继续复用 `participants`、加密身份表、`experiment_sessions`、`messages`、`chat_requests`、`ai_agent_configs`、`experiment_runs` 和 `participant_agent_assignments`。未改变 P/T 编号、均衡随机分配、Coze 提示词或续聊方式。

新增兼容迁移 `0011_experiment_entry_links.sql`：

- `experiments`：实验目录和名称，回填已有实验。
- `experiment_runs.entry_token`：唯一入口码，既有场次也分配短码，已有非空链接保持有效；仍兼容 32 位历史码。
- `experiment_runs.is_default`：保留迁移前开放的场次作为原首页入口；多个独立入口可以同时开放。
- `experiment_runs.config_snapshot`：新入口创建时保存任务和规则，后续设置变更不会改变该入口的实验条件。既有会话仍使用其原快照；旧场次首次创建新会话沿用原有设置规则。
- 用“每个实验最多一个首页默认入口”的索引替代“每个实验最多一个开放场次”的索引。

迁移不删除已有记录。不需要新增环境变量，继续使用原数据库、加密密钥、管理员密钥和网站访问码。当前工作环境已执行该迁移；其他数据库发布前执行：

```sh
node --env-file=.env.local scripts/migrate.mjs
```

原首页仅对应环境变量中的默认实验，旧签名编号链接仍然兼容。新增实验请使用对应的分组链接。

## 验证范围

自动测试覆盖新旧链接格式、复制信息、实验复制与权限、多个入口同时开放、配置快照、同名被试、不同实验相同编号、Cookie 隔离、跨组恢复和切换拒绝、停止报名后的原上下文恢复，以及按实验和入口筛选导出。原编号并发、保存失败、草稿冲突、完成状态和历史兼容测试继续运行。

数据库测试使用随机隔离 schema 和合成身份，Coze 模拟响应用于验证真实调用代码的 Conversation ID 和 Bot ID。它验证上下文接续参数，不声称验证正式智能体回复质量。
