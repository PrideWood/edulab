# 0.14.0 发布范围

当前优先发布Windows 7 SP1 64位、Chrome 69机房客户端，并更新现有教师后台。学生线上版暂缓开放，入口显示机房客户端说明，线上学生接口暂停，不作为当前实验入口。

本机包内置Python 3.8.10、完整SDK 14393 UCRT及ES2017兼容页面。两个入口均携带运行库。无需安装Python、修改System32或重启电脑。

教师后台保留课堂控制、原始数据、评分与云端备份。分析函数移到 `analysis/`，不连接应用页面或接口。

备份采用本机事务和持久队列，失败自动重试；无论学徒是否正在回复都可上传。云端回执匹配后显示同步状态。无法保证断网时即时上传，存在还原保护的机房须在关机前确认云端已接收。

检查包括Python 3.8回归、Chrome69兼容构建、客户端状态测试、生产构建、UCRT/内嵌与独立runtime文件一致性检查，以及受限学生连接的真实云端回执和数据库快照核对。机房真机仍需复测新流程。
